FoodFilled — Impact Intelligence

Interactive single-page impact dashboard for FoodFilled (FY25 baseline + proposed impact framework).

View the dashboard

Open FoodFilled-Impact-Intelligence.html in any modern browser, or serve it locally:

# Python
python3 -m http.server 8000

# then visit http://localhost:8000/FoodFilled-Impact-Intelligence.html

GitHub Pages works too — just enable Pages on the repo (source: root or /docs).
